# structural-game · 结构工程互动教学游戏

一个面向中学 STEM / 工程素养课堂的纯静态互动教学游戏。学生通过拖拽节点、连接杆件，在基于位置动力学（PBD）的实时物理引擎中搭建并测试结构，直观理解力学平衡、材料强度与重心稳定。

> 纯前端单文件实现（`index.html`），无需构建、无需服务器，双击即可在浏览器运行。

## 关卡（Levels）

| 关卡 | 内容 | 教学目标 |
| --- | --- | --- |
| 桥梁 | 在峡谷两端搭建承重桥 | 桁架、载荷分布、节点约束 |
| 高塔 | 搭建尽量高的稳定高塔 | 重心、稳定性、长细比 |
| 浮桥 | 在浮筒上搭建跨越水面的结构 | 浮力、漂浮平台、平衡 |
| 悬臂塔吊 | 悬臂末端用钢索吊钩挂载荷（塔吊式） | 悬臂弯矩、吊索受力、不卡缝 |
| 棉花糖挑战 | 塔顶放置"粘胶"棉花糖（有重量），塔不倒即过关，记录最高值 | 顶部载荷、重心偏移、失稳临界 |

## 功能

- **实时 PBD 物理求解器**：杆件刚度、节点质量、重力、地面碰撞、约束求解。
- **入口登记**：进入项目前输入学生姓名与班级（默认预填便于测试）。
- **自动评价与提交**：完成全部关卡后，将 `{姓名, 班级, 各关成绩, 总分, 是否通过}` 以 POST 发送至 QuickForm 评价接口。
- **排行榜**：从同一接口拉取全量数据，按高度/分数生成金银铜排行榜并高亮当前学生。
- **极简建筑平面图风格**：白底黑线、低饱和点缀、俯视轴测布局。

## 运行

直接用浏览器打开 `index.html` 即可。如需本地静态服务：

```bash
cd structural-game
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 配置

评价 / 排行榜接口地址在 `materials.json` 的 `submit` 字段中配置：

```json
{
  "submit": {
    "url": "https://quickform.cn/api/r5a3ly81xx",
    "auto": true,
    "rankBy": "height"
  }
}
```

## 技术栈

- 原生 HTML + Canvas2D + JavaScript（零依赖、零构建）
- 位置动力学（Position Based Dynamics）自研求解器
- 数据落地：QuickForm 开放接口（CORS 友好、自动持久化）
